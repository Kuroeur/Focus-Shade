# FocusShade

Windows 11 桌面专注遮罩工具，WinForms / Win32，.NET Framework 4.x，x64。

## 使用

双击 `FocusShade.exe`，默认请求管理员权限；在 Windows UAC 提示中确认后启动，初始遮罩关闭。点击悬浮按钮开启/关闭；按钮不接管前台焦点。图标采用 Windows 当前主题色，开启时中心出现实心圆点。

- 正常按钮为39 DIP双圆图标，圆形和窄条均用逐像素抗锯齿绘制，90% 不透明度；拖到任一显示器工作区边缘，鼠标离开约650ms后收起为6 DIP窄条，两端圆角、60%不透明度。鼠标移入展开。
- 右键悬浮球与托盘图标都打开同一个英文浮层菜单，提供 `Turn on / Turn off`、`Settings`、`Exit`，开关文字随遮罩状态变化，点击开关后菜单保持打开。悬浮球与菜单位于应用上方，菜单不接管前台焦点；设置页可以接收键盘输入，但不会替换被保留的真实应用。
- 从托盘打开菜单期间，暂时保留该显示器的任务栏及托盘可见、可操作；菜单或设置关闭后重新遮黑。Windows 任务栏是整体窗口，因此暂时显示整条任务栏。球右键菜单不显示任务栏。遮罩已开启且菜单关闭时，可通过球菜单先关闭遮罩再访问托盘。
- 快捷键可在设置中修改；默认开关为 **Ctrl+Alt+F10**，紧急解除为 **Ctrl+Alt+F9**，退出为 **Ctrl+Alt+Shift+F12**。启动时冲突会尝试其他组合，设置保存时冲突会提示并保留原快捷键。每次启动以同目录 `HOTKEYS.txt` 和悬停提示为准。紧急解除会展开按钮并移回可见区域。
- Alt+Tab / Ctrl+Alt+Tab：仅系统选择面板位于黑色遮罩上方，按钮隐藏，其他显示器和面板周围保持黑色。根据实际 shell 窗口动态调整层级，不写死主显示器或面板坐标。
- Win+Tab：暂时隐藏遮罩和悬浮球，完整显示系统任务视图，保留遮罩开启状态。跟踪真实任务视图窗口，等其关闭后重新读取前台并恢复遮罩，支持选择另一显示器上的应用。任务视图期间桌面和任务栏可见；此版本优先稳定性，不追求全程纯黑或动画无闪现。
- Win+D：窗口最小化后以独立置顶完整黑层覆盖桌面，保留开启状态；恢复窗口后重新建立应用层级。系统任务栏可能短暂闪现，当前作为已知观感限制。
- Win / Win+S：开始菜单与搜索按系统面板处理，不改变遮罩开启状态；关闭面板后恢复应用层级。
- 将应用拖到显示器顶部时，Windows 分屏布局栏可正常显示和操作；拖动结束后保持遮罩。
- 应用完整覆盖某块显示器时，不在该显示器上额外显示任务栏黑条；其他显示器继续遮黑，退出全屏后恢复任务栏盖层。无边框全屏已通过自有窗口检查；独占全屏仍受系统限制。
- 黑色区域会拦截鼠标操作，不会误点下面的窗口或任务栏。使用 Alt+Tab / Win+Tab 切换应用；聚焦窗口仍可操作。键盘输入仍交给当前前台应用。

所有紧急键候选被占用时拒绝启动。候选按 Ctrl+Alt、Ctrl+Shift、Ctrl+Alt+Shift 尝试 F12、F8、F9、F10、F11、Pause；退出优先 Ctrl+Alt+Shift。

## 构建

无需 .NET SDK。在源码目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

使用系统 `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，运行46项核心测试和19项设置测试并生成 `FocusShade.exe`。也提供 .NET Framework 4.8 的传统 Visual Studio 项目。

原生桌面回归测试会短暂显示测试窗口与黑色遮罩，只关闭、最小化自身夹具窗口；遮罩检查会临时调整背景窗口层级，完成后请求恢复：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -DesktopTests
```

## 命令

```powershell
.\FocusShade.exe --off          # 紧急解除
.\FocusShade.exe --exit         # 退出
.\FocusShade.exe --settings     # 打开设置（程序需已运行）
.\FocusShade.exe --toggle       # 开关
.\FocusShade.exe --test-windows # 两扇临时人工测试窗口
.\FocusShade.exe --inspect      # 本机窗口/显示器诊断
.\FocusShade.exe --verify       # 实际屏幕像素采样
```

诊断可能包含窗口标题；不会上传。命令仅控制当前 Windows 会话中的工具实例。

## 实现与限制

普通模式采用完整、不镂空的普通层级黑色覆盖层，放在真实前台应用及其可见 owned popup 后方；球与菜单独立置顶。背景应用放在黑层下方，任务栏使用单独黑层。临时调整过的应用置顶属性在切换、关闭遮罩和正常退出时请求恢复。Windows 桌面合成器直接处理移动、缩放和跨屏，无需按刷新率追踪空洞。外部层级请求异步执行；系统拒绝或应用卡住时保留开启状态并降频等待，紧急关闭仍可使用。异常、强制结束或应用卡住时不能保证外部窗口原属性立即恢复。

按钮与遮罩采用 NOACTIVATE / TOOLWINDOW。遮罩覆盖完整虚拟桌面，物理坐标支持负数，DPI 使用 PerMonitorV2。按钮只有状态/尺寸/主题变化时重绘，移除了原来的定时重绘与无条件置顶。主要依靠 WinEvent 事件；普通750ms核查，shell选择界面100ms核查，事件16ms合并；仅按钮拖动期间20ms补充跟踪鼠标。

默认管理员运行已在本机 MSI Afterburner 上通过现场验证。若通过兼容设置强制以普通权限运行，管理员应用聚焦时仍会暂停显示并保留开启状态。管理员权限也不保证支持受保护窗口、安全桌面或独占全屏。

系统 shell 类名/标题并非稳定公开接口，当前验证为 Windows 11 build26200中文环境；后续版本、第三方 shell 和其他语言可能需适配。安全桌面、独占全屏、提升权限/受保护窗口及反复抢置顶的程序不保证支持。系统选择界面的动画和特殊置顶窗口仍有兼容性限制；工具不是安全防窥边界。混合DPI、负坐标真实布局及每个刷新率下的逐帧性能尚未验证。详细证据见 [TEST-REPORT.md](TEST-REPORT.md)。

## 设置与卸载

菜单与设置界面为英文，共用同一个主题色浮层。点击 `Settings` 在菜单锚点向内展开，`Back` 原位返回菜单；`Close` / `Cancel` / Esc 关闭浮层，`Save` 保存后关闭。菜单点击其他窗口时关闭，设置页可保持打开；设置没有独立标题栏或任务栏按钮。默认约348×365 DIP，字号及提示内容增大时按内容调整，并限制在实际显示器工作区内。`Panel opacity` 同时控制菜单与设置的不透明度（10%–100%，默认90%），独立于悬浮球。`Button opacity` 和 `Docked opacity` 可分别调整展开按钮与贴边窄条的不透明度（10%–100%，默认90%/60%）。在快捷键字段按下组合键，再点击 `Save`。配置保存在程序目录 `settings.ini`，重新启动后读取；遮罩不会自动开启。

`Start with Windows` 默认关闭。勾选并保存后，通过当前用户的 Windows 计划任务以最高权限在登录时启动；不使用普通 Run 注册表项，不保存密码。取消勾选并保存会删除该用户的 FocusShade 任务。旧版 Run 项在保存设置时迁移或清除。移动程序后重新保存启用可更新路径，保存取消会清除旧任务。计划任务注册、实际管理员执行与临时任务清理已测试；真实注销/登录的触发时机尚未测试。

软件为便携版，没有安装器。卸载时先在设置里关闭开机自启并保存，随后选择托盘 `Exit`，删除整个程序文件夹即可。Windows 可能将新托盘图标收入通知区域的折叠菜单。
